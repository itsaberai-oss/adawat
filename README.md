# أدوات عبير الرافعي

مجموعة أدوات تفاعلية، كل وحدة تحل مشكلة محددة بلا تسجيل ولا تعقيد.

الموقع المباشر: https://itsaberai-oss.github.io/adawat

---

## الأدوات

### [فاحص المطور](https://itsaberai-oss.github.io/adawat/developer-check/)
تحقق من جاهزية مطور عقاري قبل الشراء على الخارطة، مبني على بيانات منصة وافي.

### [مكينة النقاط](https://itsaberai-oss.github.io/adawat/makinat-noqat/)
قارن أكثر من 11 برنامج مكافآت بنكية بمكان واحد، واحسب نقاطك الفعلية حسب صرفك الشهري.
